A working glossary of the "jurisdictions" mapped by this project: named traps, chambers, and enclosures produced by late-stage systems (economic, familial, legal, bureaucratic, biopolitical) that constrain, extract from, or discipline the people caught inside them.

Each jurisdiction now has its own file in [`jurisdictions/`](jurisdictions/), so it can be edited, expanded, and cited independently. This page is just the table of contents.

**How to use this document:** Each entry's file gets a rudimentary, deliberately general definition meant to hold up over time — not tied to one anecdote or news cycle. Treat the definitions as a first cut, not a final word. As you encounter new cases, sources, or sharper phrasing, edit that entry's file directly. The `Notes / Evidence / Updates` section at the bottom of each one is there for exactly that — running notes, examples, citations, revisions — so this stays a living document instead of a fixed reference. Add new jurisdictions as new numbered files; keep numbering stable once entries are cited elsewhere.
